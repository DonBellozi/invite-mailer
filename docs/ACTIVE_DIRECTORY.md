# Active Directory

Версия v2.6.0 добавляет доменную авторизацию и поиск пользователей.

## Настройка

Откройте `Настройки` -> `Active Directory` и укажите:

- сервер контроллера домена;
- порт 389 для LDAP или 636 для LDAPS;
- домен NetBIOS;
- Base DN;
- служебную учетную запись с правом чтения каталога;
- LDAP-фильтр пользователя, по умолчанию `(sAMAccountName={login})`.

После сохранения нажмите `Проверить подключение`.

## Пользователи

На странице `Пользователи и права` вводится только логин. Кнопка `Найти в AD` получает `displayName` из каталога. После этого назначаются локальные права.

Пароли входящих пользователей не сохраняются. Пароль служебной учетной записи сохраняется в базе приложения, поэтому доступ к каталогу данных контейнера должен быть ограничен.

Аварийная учетная запись из `ADMIN_USERNAME` и `ADMIN_PASSWORD` продолжает работать независимо от состояния AD.
