# Архитектура Invite Mailer

## Компоненты

### `invite-mailer`

Запускает планировщик и команды обработки:

- получение XLSX;
- импорт работников;
- отправка приглашений и напоминаний;
- обновление кеша Indigo;
- формирование отчета;
- технические и групповые уведомления.

### `invite-mailer-admin`

FastAPI-приложение административного интерфейса. Управляет тестами, шаблонами, контролирующими, настройками интеграций и сопоставлениями логинов.

### `invite-mailer-report`

nginx публикует внутренний отчет и направляет запросы административного раздела в FastAPI.

## Хранилище

Рабочее состояние находится в SQLite:

```text
/opt/invite-mailer-storage/state/invite_mailer.sqlite
```

Каталоги данных:

```text
data     – полученные и текущие XLSX;
state    – SQLite и состояние приложения;
reports  – сформированный HTML-отчет и экспортируемые материалы.
```

## Runtime Settings

`app/runtime_settings.py` отвечает за:

- первичный импорт SMTP, Indigo и доменов;
- сохранение маркера завершенной инициализации;
- применение значений из `app_settings` к текущему процессу;
- запись изменений из Web UI.

После первичного импорта значения интеграций из `.env` не являются fallback для отсутствующих ключей.

## Основные потоки данных

```text
Zimbra IMAP → XLSX → SQLite workers
Indigo PostgreSQL → локальный кеш SQLite
SQLite + шаблоны → SMTP
SQLite → HTML-отчет
Web UI → app_settings и другие таблицы SQLite
```

## Принципы безопасности

- Indigo используется только в режиме чтения;
- пароли интеграций не возвращаются браузеру;
- административные операции требуют сессии;
- доступ к отчету ограничивается внутренними сетями через nginx;
- технический идентификатор работника формируется с HMAC и не раскрывает СНИЛС;
- постоянные данные вынесены из контейнеров в bind mount.

## Планируемые подсистемы

- полные автоматические резервные копии на отдельный bind mount;
- глубина хранения последних успешных копий;
- скачивание, проверка и удаление бекапов через Web UI;
- безопасное восстановление с предварительным аварийным снимком;
- авторизация через Active Directory с локальным назначением ролей.
