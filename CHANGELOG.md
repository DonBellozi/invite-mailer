# История изменений

## 2.3.10

### Изменено

- SQLite окончательно закреплена как источник рабочих настроек SMTP, Indigo и разрешенных доменов.
- `.env` и YAML используются для интеграций только при первичной инициализации новой установки.
- Добавлен отдельный маркер завершенного импорта Runtime Settings.
- При отсутствии отдельного ключа в уже инициализированной базе используются безопасные значения по умолчанию, а не повторный импорт из `.env`.
- Документация разделена на основной README, инструкции по установке, конфигурации, обновлению и описание архитектуры.

### Исправлено

- Исключено повторное влияние значений SMTP и Indigo из окружения после перезапуска контейнеров.
- Добавлена безопасная обработка некорректных числовых значений Runtime Settings.

## 2.3.9

- Добавлен настраиваемый интервал автоматического обновления данных Indigo.
- Допустимый диапазон – от 1 до 1440 минут.
- Новый интервал применяется без перезапуска контейнеров.

## 2.3.8

- Добавлена зависимость `itsdangerous` для сессионной авторизации.
- Уточнено использование `SESSION_SECRET`.

## 2.3.7

- Добавлена сессионная авторизация административного раздела.
- Добавлены `/login`, `/api/auth/me` и `/api/auth/logout`.

## 2.3.4

- Настройки SMTP и Indigo перенесены в Web UI.
- Добавлено управление разрешенными почтовыми доменами.
- Новые параметры проверяются перед сохранением.

## 2.3.2

- Уведомления контролирующим объединены в одно письмо по каждому тесту и получателю.
- Добавлены групповые переменные шаблонов.

## 2.3.1

- Добавлены системные шаблоны и реальные тестовые отправки.
- Реализована техническая сводка без XLSX-вложения.
- Тесты перенесены из YAML в SQLite.
