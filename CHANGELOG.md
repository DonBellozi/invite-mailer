# История изменений

## 2.3.10

### Изменено

- SQLite окончательно закреплена как источник рабочих настроек SMTP, Indigo и разрешенных доменов.
- `.env` и YAML используются для интеграций только при первичной инициализации новой установки.
- Добавлен отдельный маркер завершенного импорта Runtime Settings.
- При отсутствии отдельного ключа в уже инициализированной базе используются безопасные значения по умолчанию, а не повторный импорт из `.env`.
- Документация разделена на основной README, инструкции по установке, конфигурации, обновлению и описание архитектуры.

### Исправлено

- Исключено повторное влияние значений SMTP и Indigo из окружения после перезапуска контейнеров.
- Добавлена безопасная обработка некорректных числовых значений Runtime Settings.

## 2.3.9

- Добавлен настраиваемый интервал автоматического обновления данных Indigo.
- Допустимый диапазон – от 1 до 1440 минут.
- Новый интервал применяется без перезапуска контейнеров.

## 2.3.8

- Добавлена зависимость `itsdangerous` для сессионной авторизации.
- Уточнено использование `SESSION_SECRET`.

## 2.3.7

- Добавлена сессионная авторизация административного раздела.
- Добавлены `/login`, `/api/auth/me` и `/api/auth/logout`.

## 2.3.4

- Настройки SMTP и Indigo перенесены в Web UI.
- Добавлено управление разрешенными почтовыми доменами.
- Новые параметры проверяются перед сохранением.

## 2.3.2

- Уведомления контролирующим объединены в одно письмо по каждому тесту и получателю.
- Добавлены групповые переменные шаблонов.

## 2.3.1

- Добавлены системные шаблоны и реальные тестовые отправки.
- Реализована техническая сводка без XLSX-вложения.
- Тесты перенесены из YAML в SQLite.

## 2.3.11 – 2026-07-30

- Настройки получения XLSX по IMAP перенесены в Web и SQLite.
- Добавлены параметры IMAP, точное имя вложения, глубина поиска, время проверки и часовой пояс.
- Добавлены проверка подключения, поиск файла и ручной импорт.
- Ежедневная проверка XLSX использует расписание из SQLite без перезапуска планировщика.
- Шаблон напоминания получил универсальные переменные результата и `reminder_reason`.
- Добавлена Web-справка и `docs/TEMPLATE_VARIABLES.md`.
- Устаревшие `README_UPDATE.md` и `README_INDIGO_UPDATE.md` более не используются.

## v2.5.0 – Пользователи и права доступа

- Добавлен раздел «Пользователи и права».
- Добавлен локальный список доменных логинов.
- Добавлены права «Базовый доступ», «Импорт сотрудников» и «Администратор».
- Право импорта автоматически включает базовый доступ.
- Администратор автоматически получает все права.
- Добавлено включение и отключение локальных учетных записей.
- Добавлен параметр «Разрешить просмотр отчета без авторизации».
- При отключении публичного просмотра статический отчет защищается через Nginx `auth_request`.
- Импорт участников отделен от административных настроек отдельной серверной проверкой.
- Экспорт отчетов XLSX/PDF подчиняется правилу доступа к отчету.
- Встроенная учетная запись из `ADMIN_USERNAME` и `ADMIN_PASSWORD` остается аварийным администратором с полным доступом.
- Логирование попыток входа не добавлялось.
- Проверка пароля Active Directory в эту версию не входит и будет подключаться отдельным этапом.

## v2.6.0

- Добавлен интерфейс настройки Active Directory.
- Добавлена доменная авторизация через LDAP/LDAPS с сохранением аварийного администратора из `.env`.
- Добавлен поиск пользователя в AD по логину с автоматическим заполнением отображаемого имени.
- Добавлена проверка подключения к Active Directory.
- Добавлена опциональная выдача полного доступа членам указанной доменной группы.
- Исправлено сохранение настройки публичного просмотра отчета и отображение подтверждения.
